# Моделювання та аналіз вимог до програмного забезпечення

Лабораторні роботи 

## Предметна область (Домен)
**Онлайн-книгарня "клуб читачів"**

Система забезпечує вибір друкованих видань, дистрибуцію та поштову доставку літератури. Каталог підтримує колективне авторство видань. Клієнти формують кошик, оформлюють замовлення із фіксацією актуальних цін на момент покупки та відстежують відправлення через служби доставки.
